# CODSOFT Python Tasks

This repository contains the Python projects completed as part of my CodSoft Internship.

## Tasks

### Task 1 - To-Do List
A command-line To-Do List application that allows users to add, view, update, delete, and complete tasks.

### Task 2 - Simple Calculator
A simple calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

### Task 3 - Password Generator
A Python application that generates strong and random passwords based on the length specified by the user.

### Task 4 - Rock-Paper-Scissors Game
A Python game where the user plays Rock-Paper-Scissors against the computer, with score tracking and multiple rounds.

### Task 5 - Contact Management System
A contact management application that allows users to add, view, search, update, and delete contact information.

## Technologies Used

- Python
- Python Standard Library
- Command Line Interface (CLI)

## Features

- User-friendly command-line interface
- Basic input and output handling
- Random password generation
- Game score tracking
- Contact management
