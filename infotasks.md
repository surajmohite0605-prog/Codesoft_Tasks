# CODSOFT Python Tasks

This repository contains the Python projects completed as part of my CodSoft Internship.

## Tasks

### Task 1 - Calculator
A simple calculator application that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

### Task 2 - To-Do List
A command-line To-Do List application that allows users to add, view, update, delete, and complete tasks.

### Task 3 - Password Generator
A Python-based password generator that creates strong and random passwords based on the length specified by the user.

### Task 4 - Rock-Paper-Scissors Game
A command-line Rock-Paper-Scissors game where the user plays against the computer with score tracking and multiple rounds.

### Task 5 - Contact Book
A Contact Management System that allows users to add, view, search, update, and delete contact information.

## Technologies Used

- Python
- Python Standard Library
- Command Line Interface (CLI)
